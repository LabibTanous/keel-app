# Design Audit — Master Implementation Plan

Source: 13-screen multi-agent audit against Vercel's Web Interface Guidelines + Keel's own design-system constraints (tokens, voice, honesty rule). Every finding was independently re-verified against the live file before inclusion — this is not a raw review dump. **237 confirmed findings** across all 13 screens.

**Ground rules for whoever implements this:**
- No new hex colors — every color is a `var(--token)` already in `globals.css`.
- Don't redesign `keel_handoff/design_reference/`-locked screens — only fix genuine a11y/semantics/consistency/contrast bugs.
- Run `npm test && npx tsc --noEmit` after each screen's batch.
- Keep commits scoped per screen so they're easy to review/revert.
